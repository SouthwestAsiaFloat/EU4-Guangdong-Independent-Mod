## 几何与冻结输入

- 可编辑域仅为基线五省 `5009,4197,5012,2175,5350` 的联合像素。
- 沿用 B47 v3 已落地的现代鄂豫两侧域，河南省份不能占用湖北像素，反之亦然。
- 原随州完全保留；湖北其余两省联合域重排为麻城、黄州、蕲州，修正旧蕲州居中的地理语义。
- 湖北内部以黄冈县级 GeoJSON 分组为种子：麻城/红安/罗田/英山；黄州/团风/浠水；蕲春/武穴/黄梅。
- 河南内部以信阳城区、罗山、潢川/光山/新县、固始/商城为四组。息县、淮滨不在本批，息州留在汝蔡。
- 县域投影后进行四向连通的边界调整，避免信阳、罗山成为难以点击的小地块。面积目标独立于发展度，不按发展度重新缩放地图。
- 大别山 `5354`、可通航河流、其他省份的所有像素均锁定。未新增特殊邻接。
- `batch_manifest.json` 保存 RGB、ID、母省、县域数据哈希和最终逐行像素段。现行正式位图是执行目标；旧整张预览不用于覆盖现行地图。
- `pre_b79/` 保存改动前位图及原数据；正式图为 `b79_applied_preview.png`。

## 重放顺序

历史 B47/B43/发展度脚本保留为旧阶段生成器，不能将其旧面积、国家省份数量及发展度断言当作 B79 验收条件。完整重放须先完成所有历史地图阶段，再执行 B79，之后运行依赖当前 Area 的 B49 贸易投影及宗教/学宫终端步骤。终端入口已接入 B79，防止历史脚本恢复随黄五省或旧发展度。

```sh
python3 tools/map_pipeline/apply_b79_suizhu_xianhuang.py --apply
python3 tools/map_pipeline/apply_b49_eight_node_trade_network.py --check
python3 tools/map_pipeline/finalize_zhx_province_history.py --check
python3 tools/encode_eu4_chinese_localisation.py --check
```

`--prepare` 仅用于首次冻结；正常重放使用 `--apply`，不能从已细化地图重新推导母省。
