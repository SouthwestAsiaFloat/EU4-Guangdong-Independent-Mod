## 玩家规则

楚国开局领有长沙、衡、州、权、安成、鄂六个附庸。熊方策在位期间，按当前直接非朝贡属国数量计算分权减益，新收属国也计入：

| 属国数 | 国家税收 | 人力恢复速度 | 全局省份贸易竞争力 |
|---|---:|---:|---:|
| 6个及以上 | -30% | -30% | -30% |
| 5个 | -20% | -20% | -20% |
| 4个 | -10% | -10% | -10% |
| 3个及以下 | 无 | 无 | 无 |

数量与减益按原生月度脉冲刷新。普通外交吞并、主动释放均可降低数量；首任君主在位时重新达到四个，会恢复相应减益。不提供特殊吞并、额外过关奖励或释放惩罚。

首任君主离位时立即记录数量。三个及以下永久安全结束；四个及以上锁定“楚封离议”，进入天下公议，已有议题时等待其结束。锁定后再减至三个不能撤销事变。

表决持续365日，同意严格多于反对时，释放结算当日楚国所有属国。平票或反对较多则保留附庸，结算时的属国获得20年（7300日）独立倾向+50个百分点。新增附庸不继承后遗症；旧附庸独立或转属时不生效，在期限内回到原楚国宗主下则恢复剩余时长。两种结局均永久解除开局减益，后任君主离位不会重开。

使用现有公议界面与改票入口；天子不投票、不额外批准或否决。楚国AI反对；其属国独立倾向达到50则赞成，否则反对；其他成员优先按双方宿敌关系赞成，否则盟友或好感至少50反对，好感为负赞成，其余弃权。

## 剧情与接入

剧情围绕熊立辉身后、熊方策分封及诸伯寻求直接奉周展开。开局背景按钮保留“受命不迁，生南国兮。”，悬停说明补齐安全门槛、公议与后遗症；事件包含《诸伯的印信》《旧约无主》《各奉周命》《留席未必同心》《可交付的国政》等。

机制集中于 `zhx_chu_crisis` 的事件、效果、触发器、on_actions及两类修正文件；复用 `zhx_council`、`zhx_system.23` 的公议与截止日。中文源文为 `localisation_source/028_zhx_chu_crisis_readable_utf8.txt`，背景按钮通过开局manifest生成。

数值结算在原定截止日执行；结局文案通过国家通知标记交给原生月度事件投递，可能比结算晚至一个月。完成后保留的数量变量是最后快照，不再代表实时附庸数。
