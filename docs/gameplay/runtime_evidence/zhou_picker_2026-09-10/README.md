- 1445.1.1 暂停：第一页热河、卓索图、昌平、密云；第二页通州、涿州、辽河套、广宁；第三页滦州、遵化。连续前翻两页、后翻两页、再次前翻，无弹窗丢失；末页只有两个有效省份且无下一页。
- 第三页选择遵化，确认文字对应科尔沁持有的遵化。取消后保存 zppcancel.eu4；cancel-state.json 证明选择锁和请求锁清除、无年度冷却、十省仍归科尔沁。
- 实际重新载入 zppcancel。原生外交间隔限制短期重开，因此推进测试日期到 1445.2.14 后再次通过正式入口打开。测试期间处理了常规事件通知。
- 再次翻到第三页，选择遵化，点击“返回省份列表”保留第三页；重新选择并确认发送，AI 即时接受。
- 保存 zppafter.eu4。after-send-state.json 证明仅 5213 遵化 owner=YAN，其他九省 owner=KRC；CZH 选省锁与各请求锁清除，KRC 正式生成年度索还冷却。

01 至 05 截图对应分页往返和遵化确认，06 是发送后画面。audit_save.py 可对本机 save games 中保留的 zppcancel.eu4 / zppafter.eu4 重跑；JSON 包含完整存档 SHA-256。游戏结束时保持暂停在测试存档，安装目录临时 zppsetup.txt 已移除，证据副本保留。
