## 根因与修复

用户两份异常报告（13:40、14:33）均为 SIGSEGV：`CCasusBelliEffect::GetDesc → CEventOption::GetDesc → CEventWindow::GetOptionEffectTooltip`。触发点在选项悬停描述生成；并非据此证明 `cede_province` 崩溃。原确认选项间接展开 AI 拒绝效果中的 `add_casus_belli`，即使包在 `hidden_effect` 中仍会走描述代码。

将拒绝的国家后果移入隐藏事件 `.24` 的 `immediate`，由拒绝国作为 ROOT 在次日结算，CB 使用 `target = ROOT`；省份处罚、冷却与请求锁仍在原请求结算。派发链的嵌套 `else` 改为明确条件的 `if`，并先判断拒绝，以防接受清缓存后误走拒绝。新回归检查保证可见选项不能直接展开 CB 效果，同时保留分发顺序约束。
