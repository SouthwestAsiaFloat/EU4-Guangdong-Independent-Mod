# 周天下领土修复（2026-09-08）

本次规则由用户在 grill-me 讨论后确认。修改只发生在当前仓库；外部安装副本没有同步，
也未启动游戏写入日志或存档。以下静态、离线结果不能替代引擎内验收。

## 四项修复

1. **省份图标**：辽河套 5206、广宁 5207、卓索图 4672 的残留不是省份同时加入贸易
   公司的证据。原生按钮从 x=20 开始，原生静态图标从 x=32 开始，各宽 42 像素；旧
   周字遮罩只宽 42，漏掉右 12 像素。保持周字本身大小和位置，四态背景改为 54×42，
   TGA 横条改为 216×42，覆盖与点击区域完整包含两个原生控件。
2. **外交分类**：专属本地化键和中文编码原本正确；补上本地其他 mod 使用的
   `DIPLOMACYACTION_CATEGORY_` 空分类兼容键，同时保留专属键。引擎究竟显示哪个键
   需实机确认。删除生成器中的废弃手工按钮模板，使重新生成与现有原生外交列表一致。
3. **好感惩罚**：移除省份仍使当前皇帝对实际剥离国 -25 好感，叠加最低 -100，每年
   恢复 1；移除修正的零月有效期，手动与 AI 路径均明确写入 100 年上限，实际随数值
   衰减结束。退出及强制归还的 -100／年恢复 2 同样补上 50 年有效期。
4. **索还规则**：见下表。提示拆开说明属国入口、战争条件与实际持有国冷却，取消
   永远写成红色的整段失败提示。AI 事件继续使用相同判定和归还器。

| 条件 | 当前规则 |
|---|---|
| 天下登记 | 省份必须有周天下地块旗标 |
| 持有者核心 | 有核心即豁免，成员与外部国家一致 |
| 解放豁免 | 成员从外部国家收复地块的现有本任所有者豁免保留 |
| 归还对象 | 必须有合法核心国家；在世者必须仍属于周天下，灭亡者必须有历史周身份 |
| 多个省份 | 选合格候选中发展度最高者，不把未到冷却时间的其他持有国混入 |
| 属国 | 在宗主国外交页提出；皇帝自己的直属属国例外，可直接处理 |
| 冷却 | 每个实际持有国独立 365 天；宗主答复不会使其他属国共享此冷却 |
| 再次索还 | 冷却结束后可再次索还仍非法的同一省，不再永久排除 |
| 战争 | 双方彼此交战禁止，各自与第三方交战允许 |
| 排队后变化 | 地块易主、完成核心、失去合法归还对象、与持有者开战或发起者失去皇帝身份时取消处理 |
| 优先级 | 直接前任合法持有者 → 其他前任合法持有者 → 其他合法核心国家 |
| 灭国复国 | 只转交争议省，登记为普通成员；不补皇帝核心，不自动补大诸侯席位 |
| 原生外交限制 | 原生行动没有发送时锁定省份的脚本钩子，答复时重新选择并复核合格省 |

历史身份在天子／成员登记时记录，成员退出清理不会抹掉历史。旧存档通过 v15 迁移为
当前成员补历史身份，灭亡的开局成员按原开局名册识别；旧版本中已灭亡且从未记录历史的
动态加入国无法凭空恢复其历史证据。v15 保留原冷却日期与待答复请求，只清除旧省份永久锁。
