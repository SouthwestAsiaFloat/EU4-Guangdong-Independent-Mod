# 天下事变投票国家名单

## 操作

天下公议处于天下事变投票期时，悬停票数行或本国立场，显示赞成、反对、弃权、尚未投票四组国家；悬停下方投票按钮，只显示该选项的国家名单及改票说明。点击按钮仍执行原有投票，不增加额外窗口。

适用于楚封离议、晋封公议与礼崩乐坏事变的共享控件。名单按当前有效投票资格筛选，天子不参与事变投票；尚未投票不归入弃权。每国一票，不显示大辩论的加权票。

## 实现

`tools/generate_zhx_council_vote_tooltips.py` 生成只读的自定义本地化与中文源文，`common/custom_gui/zhx_tianxia_gui.txt` 接入悬停提示。只读国家名称函数不修改票数、AI策略或结算。

实测发现旧 `zhx_roster_*` 缓存已随盾徽面板退役，导致此前的名单函数无国家可读。现在 `zhx_build_gui_roster` 仅在投票开放期间构建有效投票国缓存，保留现有天命页名册维护。开面板和现有名册刷新入口负责重建，悬停直接读取各国当前票旗；改票无需重开面板。退出成员或灭亡会被实时资格筛选排除；新成员进入缓存依赖现有刷新或重开面板。

缓存上限200，与原分配器一致，生成器共享容量常量。没有恢复退役盾徽控件，也没有添加自循环事件。生成检查同时确认缓存生产入口存在，避免仅验证文本生成、漏掉空缓存的问题。
