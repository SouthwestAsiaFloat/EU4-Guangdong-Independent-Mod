# 周天子政府与天子禁卫

## 当前实现

周国 CZH 在新战役历史中采用独立的第一层政府改革 `zhx_tianzi_reform`，显示为「周天子制」，使用冕旒冠图标。它是固定帝国等级的世袭君主制，采用正统性，不启用原版贤能值或旧制派系。

改革只向当前周天下天子开放；开局旗标尚未初始化时，仅周国具有历史资格。普通诸侯不能通过提高政府等级或手动选改革取得此身份。既有 `zhx_set_tianzi` 任命入口同步改革，月度事件只检查相关国家；不以一个新的独立旗标冒充天子身份。更换第一层改革使用原生直接替换，不重建君主、继承人或阶层。

| 基础收益 | 数值 |
|---|---:|
| 外交关系位 | +2 |
| 改善关系 | +20%，对所有国家 |
| 贵族忠诚均衡 | +10 个百分点 |
| 贵族影响力 | +5 个百分点 |
| 年度威望 | +0.5 |
| 年度正统性 | +0.5 |

不保留原版改革额外的治理容量 +500，也不继承原版对三个阶层降低影响力的修正。

## 天子禁卫

特殊步兵显示名称已按用户要求改为「天子禁卫」。复用 EU4 1.37.5 的原生 `musketeer` 特殊步兵类别，在原生军队招募界面招募，需要对应的 Domination DLC 支持。它随普通步兵科技使用单位，不是新建的普通步兵单位、雇佣兵团或国家全军修正。

初版兵额为 **6 团**。不设置随全国陆军上限增长的比例。以下是尚待战斗和经济实测的初版配置，不能称为已达到八千抗衡一万的平衡结果：

- 禁卫火力伤害总计 +50%：原生类别自带 +15%，专属训练再加 +35%。
- 禁卫冲击伤害 +50%。
- 禁卫维护费 +20%。
- 不改招募费用、人力消耗、补员速度、纪律、士气或减伤。

`zhx_wangshi_training` 带有 `is_musketeer_modifier = yes`，只作用于此特殊步兵类别。只有天子取得训练修正，普通步兵不享受它；丢失改革时移除训练。原生类别的基础属性文件未改，其他国家的原生火枪卫队不获得天子的额外数值。**类别名称的汉化键是全局槽位**，因此其他原生消费者也会看到「天子禁卫」这个类别名；这不是按国家动态命名系统。

为后续两条改革路线预留受限扩编效果：

- `zhx_tianzi_expand_government_guard`：政府路线增加一阶段。
- `zhx_tianzi_expand_council_guard`：周天下共同改革路线增加一阶段。

初版每条路线最多三阶段，每阶段 +2 团；本系统最多 18 团。即便阶段变量异常超过三，改革也只提供已列出的六项固定增量。**这些是实现阶段的可调整预留值，不是用户定案的后续改革设计；目前没有挂接任务、决议或自动推进入口。** 普通游戏开局额度保持六团，后续节点按用户要求留待单独设计。

## 双都王畿

仅 **688 开封、1836 洛阳**在省份历史中登记 `zhx_wangji_tax`；汝州和偃师不登记，也不在潜在适用省份中。

加成为地方税收 +50%，仅所有者是当前天子且采用周天子制时生效。省份触发式修正由引擎重新判断，不依赖月度转移缓存；其他国家夺取两都后不能享有额外收益，但普通省份收入不受此限制。

+50% 是初版待测参数。财政目标仍是「养满开局禁卫、全额军费时小有盈余」，尚未完成满编、顾问和要塞开支统一基准下的实机核算。两都未来通过任务书或分阶段改革提高收益的方案尚未设计。

## 儒家开局与圣旨边界

周国的既有开局清单原本就指定儒家，权威状态仍由 `zhx_opening_school.1` 按清单分配，初始践履 25。本次在周国国家历史补上 `religious_school = zhx_ru_school`，供开局选择／初始化前显示。

另修正通用学派生命周期事件 `zhx_doctrine.92` 的时序边界：若一个清理回调排队后，开局事件已经赋予合资格国家学派，执行时只同步原生显示，不再清除刚建立的学派状态。实际不合资格或无学派国家仍走原清理路径。这一防护经过源码检查；用户反馈的学派缺失尚未完成本次重启后的实机复现与验收，不能断言仅有这一根因。

改用正统性以后，旧圣旨的 20 贤能值费用不能直接沿用。由于用户要求圣旨后续整体设计，本次在两处既有通用入口增加停用条件与中文说明，并在执行效果再检查资格。**没有改扣正统性、行政点或金钱。** 周天下公议、礼统与既有共同改革系统继续沿用原实现。

## 文件与验证

主要机制文件：

- `common/government_reforms/zzz_zhx_tianzi_reforms.txt`：第一层改革、固定兵额与预留增量。
- `common/scripted_effects/zhx_tianzi_effects.txt`：任命同步、训练与扩编接口。
- `common/event_modifiers/zhx_tianzi_modifiers.txt`：仅特殊步兵生效的训练属性。
- `common/province_triggered_modifiers/zhx_wangji_modifiers.txt`：双都税收。
- `common/government_names/00_aaaaa_zhx_tianzi_names.txt`：天子与王朝称谓。
- `localisation_source/025_zhx_tianzi_readable_utf8.txt`：可读中文及编码输出源。

未改政府或招募 GUI 根；使用原生第一层政府改革槽和原生特殊步兵招募控件。`common/governments/00_governments.txt` 是既有全文件覆盖，本次只加入一个改革 ID。

`python3 tools/validate_zhx_tianzi.py` 检查改革值、169 个资格／双都税收／扩编边界组合、儒家历史与清理防护、圣旨资格、图标和本地化。现有诸侯、外交、学派、开局学派、学派改革与客卿学派检查均通过。
