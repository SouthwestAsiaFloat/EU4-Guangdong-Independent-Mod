## 已实现

| 规则 | 实现 |
| --- | --- |
| 政治成员与省籍分离 | 国家成员旗标继续决定公议、晋爵、王命、勤王资格；省旗标仅决定周土。迁都或失去全部周土不自动退盟。新成员自行登记省份。 |
| 护土与犯盟 | `zhx_is_tianxia_province` 统一省籍接口；护土要求成员／天子持有登记周土。战争无核心夺取成员登记周土才触发原犯盟队列；外国间争夺及未入籍地不新增犯盟。登记、剥离、退出、贸易公司修复、易主、解散均刷新护土。 |
| 内部索还 | 发起者改为周天子；持有者须为成员，独立或隶属周天下宗主。天子直属成员属国直接答复，其他属国由周天下宗主答复；外国及外国宗主之下的成员排除。完成核心、本任解放豁免、无合法接收国均阻止索还。 |
| 退盟与复国 | 决议／按钮共用独立、和平资格及退出效果，先弃爵并取消本国待办，清直属周土、结算一次代价，再清成员。二十年禁入保护公共登记与索还复国入口，主动弃爵者不经复国恢复旧爵；正常再入盟从子开始。正常灭亡档案恢复保留。 |
| 告急 | 接受与拒绝共用答复时有效性检查；实际拒绝时求援国对该天子增加单项 -50 好感，最低 -200，`yearly_decay = 5`。没有告急不处罚；删除自动未参战扣天命检测。 |
| 政治权力与天命 | 索还、解放 CB、政治权威加成、改革执行授权及执行者态度评分归周天子／首席诸侯；天命继续承担独立资源奖罚。周天子受成员宗主控制时的月度政治权力变动也脱离原生天命脉冲。 |
| 可选天命奖罚 | 无天命持有者仍可入籍／剥离／退盟，首次奖励账仍结清、不补发。外国军事占领仅扫描成员登记周土，每省每月 -0.005。外国战争灭侯 -10 由回调登记到当时天命持有者，下次国家月度脉冲结算；此前失去天命则清除该笔，不转扣新持有者。外交吞并／整合不新增这一附加罚。 |
| 改革 | 全国发展度票重；保留天子／首席诸侯权力分配；天命至少 50，通过清空且不扣稳定。撤回保留普通成员 -10、原推行国 -50、自我排除、同项最低 -100、基础年恢复 2；移除零月有效期，延迟确认重新检查权限。 |
| 解散 | 仅要求占领天子与现存七大诸侯首都；不销毁原生天命。清省籍、爵制、天子制、王畿与训练收益、公议、王命／勤王待办和周天下特殊关系。现存军队不删除。初始化与政治入口受解散旗标保护。 |
| 生成与界面 | 保留远端 `province_window`、`celestial_window` 布局及共享神罗／贸易公司位置遮罩；保留本地公议名字名册、礼乐预估及生成器。去除重复基础 trigger，保留统一 v13–v16 调度。 |

晋爵的全国发展度／直属城市数、王命的全国收入／人力／迁民候选、公议系统沿用本地。地图、省份历史、楚开局、共和国、学派与学宫没有因本次整合而重设计。资源名称仍兼容远端“王命”界面，在新说明中区分原生天命与王命行动。

## 状态失效处理

`zhx_membership_lifecycle_effects.txt` 提供本国待办取消及省份请求取消，普通退出不会关闭其他国家的勤王战争。共同晋爵只清当前申请者对应的议题，子升伯使用本地清理入口。解散另外关闭全局勤王并清王命队列。

索还回复重验实际主人、核心、解放标记、接收资格、政治发起人及当前宗属关系。合法归还使用既有合法转移标记，避免进入犯盟队列。无关省份易主不再解除本国其他省份的请求锁；旧已取消弹窗不解除另一省份的新锁。

以下 15 个程序全部通过：

- `test_gdd_tianxia_buttons.py`：33 个按钮、退出、登记与解散源码执行测试。
- `test_zhx_startup_lifecycle.py`：9 个初始化／生命周期测试；覆盖本机原版、依赖与本地历史后的模型为 68 个周天下国家、326 块初始周土、7 个大诸侯席位。
- `test_zhou_province_integration.py`：9 个本轮定案回归，涵盖无天命奖励账、禁入与弃爵再入盟、无周土成员、分离权力、解散清理、旧索还锁和拒绝告急契约。

- `validate_zhx_ritual_warscore.py`（810 个升降场景）、`validate_zhx_ritual_tooltip.py`（10,752 个年度场景）。
- `validate_zhx_diplomacy.py`、`validate_zhx_wangming.py`（9,360 个容量场景）、`validate_zhx_qinwang.py`（3,456 个评分组合）。
- `validate_zhx_merit_store.py`、`validate_zhx_tianzi.py`、`validate_zhx_council.py`。

另外核对中文编码 `--check`、名册生成幂等、脚本括号、跨文件 effect／trigger 唯一性、`git diff --check` 及地图／历史路径零变化。旧测试中“拒绝告急无副作用”“外国可索还”“附庸可退出”“解散原生天命”“退休名册绝不能分配名字缓存”等断言已按访谈替换，同时保留对相应边界的正反例。
