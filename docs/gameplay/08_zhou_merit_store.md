# 叙功行赏与二十五年诸侯改选

## 定位与实现状态

盟功同时服务两种玩家：大诸侯用本届盟功竞争七大诸侯与首席诸侯，小诸侯也能把可用盟功换成十年诏令。它不是单纯的“强国排行榜”，也不是一次性货币；当前版本已经完成脚本、界面、AI消费、旧系统迁移与实机闭环。

本页是盟功制度的当前权威说明。早期文档中“方伯”“议政诸侯”的设计不再作为实现依据。

## 三本账

| 账本 | 用途 | 是否消费 | 是否换届归零 |
|---|---|---:|---:|
| 可用盟功 `zhx_merit` | 在“叙功行赏”中请领诏令 | 是 | 否 |
| 本届盟功 `zhx_merit_term` | 排定本届前七名 | 否 | 是 |
| 终身盟功 `zhx_merit_lifetime` | 本届同分时破同 | 否 | 否 |

三本账从同一个公共入口增加。只有可用盟功钳制在 `0—100`；消费不会倒扣本届与终身成绩。国家退出周天下时，三本账与本届资格一并清理。

## 盟功来源

- 每年按总发展度获得基本盘：低于100为 `+1`，至少100为 `+2`，至少250为 `+3`，至少500为 `+4`。
- 周天下国家作为战争胜方击败周天下以外的战争领袖：主动盟功 `+10`；当前天下显学仍可追加原有评价差异。
- 正式参与一次天下大辩投票：主动盟功 `+10`；投中最终结果另得少量盟功。
- 合法勤王胜利预留公共接口 `zhx_reward_qinwang_victory`：主动盟功 `+10`，供后续完整勤王战争链调用。

“主动盟功”会写入 `zhx_merit_active_contribution_this_term`。只有本届至少完成一次主动贡献的周天下成员，才有资格进入前七名；仅靠发展度基本盘不会自动成为七大诸侯。

## 二十五年改选

- 一届二十五年；开局沿用团队既有的七大诸侯与首席诸侯，第一次正式换届在二十五年后发生。
- 合格国家依次比较：本届盟功、终身盟功、是否为现任七大诸侯、威望。
- 前七名获得 `zhx_major_feudatory`；第一名同时成为全局事件目标 `gdd_principal_vassal`。
- 名额允许空缺，不做任期中途递补；席位只在换届时统一结算。
- 换届后本届盟功、资格旗标与名次缓存归零；可用盟功和终身盟功保留。
- 七大诸侯获得恒定 `+10` 力量投射；首席诸侯额外再得 `+10`。失位时从同一不衰减来源扣回，不遗留永久残值。
- 结算直接刷新团队既有天命页名册，不另建第二套盾徽或国家列表。

## 叙功行赏

每项诏令花费 `50` 可用盟功，持续十年。同一类别在诏令失效前只能保留一项，因此最多同时拥有四项。

| 类别 | 诏令 | 十年效果 |
|---|---|---|
| 抚民理政 | 王命赈恤 | 全国叛乱度 `-2`；稳定度花费 `-10%` |
| 抚民理政 | 整饬吏治 | 每月自治度 `-0.05`；年度腐败 `-0.10` |
| 通商劝业 | 盟市通商 | 贸易效率 `+10%`；全局贸易力量 `+10%` |
| 通商劝业 | 劝课百工 | 建造花费 `-10%`；发展成本 `-5%` |
| 整军守圉 | 假节整军 | 陆军士气 `+5%`；人力恢复速度 `+10%` |
| 整军守圉 | 缮城守圉 | 要塞防御 `+15%`；要塞维护费 `-15%`；敌军损耗 `+1` |
| 褒功修盟 | 王命褒功 | 外交声誉 `+1`；年度威望 `+0.5` |
| 褒功修盟 | 弭兵修盟 | 改善关系 `+20%`；外交官 `+1` |

AI每年最多购买一次：战争中优先整军守圉，高腐败或高自治优先抚民理政，其余情形低频随机选择可用类别。

## 呈现与可读性

周天下面板下半区采用“功簿＋赏令”的两层结构。上方功簿同时显示可用盟功、本届成绩与实时名次、终身盟功、第七名门槛、距换届年数和本届主动贡献资格；下方四张赏令册页按 `2×2` 排列抚民理政、通商劝业、整军守圉与褒功修盟。卡框与按钮复用原版图像资源，四类分别使用禾穗礼器、刀币工矩、戈斧城垣、玉璧盟书四枚透明底青铜浮雕徽记；所有名称、价格和状态仍由游戏字体动态绘制，不烙进位图。

每项赏令旁显示一个短状态签：`可请`、`已颁`、`同类封`、`功不足`或`非诸侯`。因此按钮灰显时，玩家可以直接分辨是盟功不足、自己已经持有该王命，还是同类另一项王命正在生效；四张册页仍然完整呈现给旁观者，但非周天下诸侯无法购买。

标题“叙功行赏”可悬停查看盟功定义、发展度岁计、攘外、公议、勤王四类来源，以及三本账、敕赏和七大诸侯资格的关系。八个按钮只显示中文名称、价格与效果；内部旗标、变量、触发器和脚本效果使用隐藏包装，不会泄露给玩家。窗口默认锚定在顶栏下方，完整酬功区无需先手动拖动才能操作。界面构图参考[无字资产方案效果图](concepts/zhx_merit_awards_ui_mockup_v1.png)，正式实现不直接使用图中生成式文字。

## 实机验收（2026-09-01）

使用全新1444战役和南海存档分别复核：

1. 注入八国分数后，酬功区显示可用 `100`、本届 `100`、第 `1` 名、第七名门槛 `40`、换届尚余 `1` 年。
2. 早期实机验收时价格仍为 `25`，购买诏令后可用盟功从 `100` 降至 `75`；该证据验证了扣款、同类互斥和悬停显示链路。当前正式价格已调整为 `50`，相同余额购买后应降至 `50`。
3. 执行换届后，南海出现在天命页既有“首席诸侯”位置，其他六国复用既有七大诸侯席位。
4. 多轮重启后，`error.log` 不含 `zhx_merit`、盟功GUI绑定、无效威望修正或可定制本地化相关错误。
5. 每轮均通过游戏菜单正常退出，并确认EU4进程关闭。

## 扩展接口

- 普通盟功奖励统一调用 `zhx_add_merit = { amount = N }`。
- 能授予改选资格的贡献统一调用 `zhx_add_active_merit = { amount = N }`。
- 合法勤王胜利调用 `zhx_reward_qinwang_victory = yes`。
- 新商品必须补齐：事件修正、购买效果、类别触发器、GUI按钮、中文悬停和静态契约；不得直接在界面按钮中展开玩家可见脚本条件。
