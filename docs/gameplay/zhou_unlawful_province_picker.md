# 周天下索还：手动选择省份

2026-09-10，工作区实现。入口为外交页“周天下 → 索还非法领土”。

## 玩家流程

1. 点击外交行动后打开合格省份列表，每页四块，显示省名及实际持有国；可前后翻页。
2. 选择一块后打开确认事件，显示选定省份、实际持有国、答复国，以及发送按钮悬停中的 AI 回应预测。
3. 确认才设置请求锁和实际持有国的 365 日冷却。AI 按既有评分立即处理，玩家答复国次日收到接受／拒绝事件。
4. 返回列表或取消不产生 365 日索还冷却；原生外交入口仍会消耗外交官行程并施加短期外交间隔。一个发起国同时只能打开一个选择流程，避免分页状态互相覆盖。

独立成员的列表包含自身与直接成员属国的合格土地。天子直属成员属国的外交入口仅列该属国自己的土地。既有成员身份、核心、合法接收国、战争、属国关系及实际持有国独立冷却规则继续生效。

选中省份和持有国通过本次事件链的局部目标保存。确认时、对方答复时都重验；易主、完成核心、失去合法接收国、发生不合格宗属变化、失去天子资格或解散周天下会使请求失效，不会自动改索其他省份。AI 天子季度自动索还继续使用最高发展度选省规则。

## 实现与接口证据

本机原版版本：`launcher-settings.json` 声明 EU4 v1.37.5.0 Inca (491d)。

原版 `common/new_diplomatic_actions/00_diplomatic_actions.txt` 将神罗索还声明在 `static_actions`（第 27 行），自定义行动范例提供国家级条件与回调。原版 `interface/countrydiplomacyview.gui` 的神罗索还窗口包含 `provincelist`，但在本次查看的接口中未找到将该列表绑定到自定义行动并传回所选省份的契约。因此本实现使用原生外交行动入口和标准国家事件列表，没有复用或覆盖神罗选省窗口；未新增 GUI 全文件覆盖。

| 接口 | 本次作用域与用途 | 已有依据 | 实机状态 |
| --- | --- | --- | --- |
| `require_acceptance = no` / `on_accept` | 外交发起国为 ROOT，目标国为 FROM；回调只打开本国选择事件 | 原版自定义外交 `cancel_dummy` 范例；项目勤王入口 | 正式入口实测通过 |
| `save_event_target_as` / `country_event` | 省份、持有国、答复国、天子随 .20/.22 → .21 → .11 事件链保留；不用全局事件目标 | 离线 Effects 条目；项目既有 .10 → .11 索还路径 | 分页、确认、AI 归还实测通过；玩家答复未测 |
| `every_owned_province` / `every_subject_country` | 答复国及直接属国枚举；省份内 PREV 是持有国，切回 ROOT 后 PREV 是候选省份 | 原有索还枚举效果；离线 Scopes 条目 | 十省三页实测通过 |
| `check_variable` / `is_variable_equal` | ROOT 国家持久临时变量；offset 为已跳过条数，slot 为本页候选序号；阈值比较为大于等于，槽位用相等比较 | 原版 `01_scripted_effects_natives_and_colonization.txt:194`；原有最高发展度比较 | 十省三页实测通过 |
| `country_event = { … days = 1 }` | 玩家答复国，显式 `ai = no` 分支发送 .11；AI 使用原有接受／拒绝效果 | 项目 `zhou_diplomacy_runtime_2026-09-10.md` 的玩家分发经验 | 本请求路径未测 |

`common/scripted_effects/gdd_tianxia_picker_effects.txt` 管理分页；`events/gdd_tianxia_territory_events.txt` 的 .20/.22 管理交替分页、.21 管理确认，.11 保留答复。`gdd_tianxia_unlawful_selection_valid_trigger` 共用候选资格与确认资格。解散清理选择锁及分页变量。

## 翻页消失修正

用户实机报告：能看见“下一页”，点击后窗口消失。旧代码在 .20 选项内同步再次触发 .20，存在当前事件尚未移除时重入自身的问题；此前分页模型只直接调用构建效果，遗漏了这个事件切换。改为 .20 与 .22 两个相同内容的事件交替翻页，确认仍用 .21，不增加日期延迟。

新增回归直接执行真实上一页／下一页选项，连续前翻两页再后翻两页，检查跳转目标不是当前事件、偏移量和显示省份正确；静态校验同时防止两个页面内容漂移。31 项领土／选省测试及领土静态校验通过。此修正已重新进游戏验证，暂停中连续前后翻页没有窗口消失；事件重入为结合症状和代码得出的定位，未取得引擎调度跟踪证据。

若旧版窗口已经消失、外交入口仍提示先完成选择，加载修正版后可在受影响的玩家天子国家控制台执行 `event gdd_tianxia_territory.23`。这只清分页锁和临时变量，不清已发请求或年度冷却；仅用于消失窗口的恢复。
