# 合并后周天下开局与生命周期修复

本轮从 `update-staging` 的 `aeaa94b` 开始，仅修改仓库文件；原版和两个汉化依赖只读，没有启动或操作 EU4，没有修改安装副本和存档，没有提交或推送。

## 已确认的问题与处理

### 开局周土漏登记，以及跨文件初始化重名

`zhx_system_effects.txt` 与 `zhx_merit_store_effects.txt` 都定义了
`zhx_migrate_tianxia_system_v12_to_v13`；前者登记周土地块，后者初始化盟功账本、二十五年任期和诸侯力量投射。
`zhx_system_effects.txt` 与 `zhx_diplomacy_effects.txt` 同时定义了
`zhx_migrate_tianxia_system_v13_to_v14`；前者修复周土／神罗重叠，后者初始化外交。

这两组都是加载层面的命名冲突。两个脚本块分别存在、各自语法正确，并不代表游戏会同时执行两边。
上一轮逐文件检查和手动预置成员状态的按钮测试没有覆盖此问题；原来的离线加载器还会静默覆盖重名定义。

现在每个版本迁移只在系统文件中定义一次，统一调用独立命名的功能初始化器。
周土、盟功和外交各有初始化标记；新开局两边功能都会执行，重复运行不会重新发奖励。
开局直接登记成员和天子所有非神罗直属地块，不要求完整核心、和平控制或玩家手动点击，且不增加王命。
实际开局历史覆盖中没有成员持有神罗地块。

新增 v16 修复入口，旧档读取时处理被重名冲突漏掉的功能：

- 全球既没有周土标记、也没有任何永久入籍奖励记录时，补建当前周天下国家的地块名录。
- 已有周土或入籍记录时保留现有边界，避免把玩家移除的土地、后来征服的土地重新自动加入。
- 旧版盟功任期已经运行时保留账本、剩余年份和既有奖励；没有初始化过时建立完整任期。
- 已进入 v14 的旧档保留尚未结算的犯盟／灭侯队列。
- 已解散的周天下不会被此修复重新建立。

因此，**已有部分手动入籍记录的旧档不会自动补全其余地块**。验证“所有成员地块开局就属于周天下”应使用重新启动本 Mod 后的新开局，而不是继续使用已手动改过边界的测试档。

### 皇帝更替后，域外吞并扣错王命对象

域外国家完全吞并成员时，旧效果固定向 `CZH` 扣除 10 王命。
现改为验证并作用于当前 `EmperorOfChina`；一次吞并的去重标记继续保留。

### 解散后仍残留新版诸侯效果

旧解散流程直接清掉诸侯身份，没有撤销新版七大诸侯／首席的力量投射。
现在先撤销对应的 +10／+20，再清理身份；同时清理请封申请、主办国／申请国目标、盟功排名目标、任期与排名账本，并退出诸侯专属政体改革，保留无关上层改革。
